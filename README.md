# Pumpkin Toss — スクリーンで遊ぶ文化祭プロトタイプ

2026年10月25日の文化祭に向けた試作です。
大きなスクリーンにカメラ映像を映し、片方の人が手でつかんで投げたカボチャを、もう片方の人が画面の中でかぶります。
最初に12秒のお手本を繰り返し表示するので、カメラを始める前に体験の流れを見られます。

## コードの共有・公開

共有用のURL: **https://kouyadoufu-1214.github.io/pumpkin-toss/**

GitHubのコード: https://github.com/Kouyadoufu-1214/pumpkin-toss

遊ぶだけならGitHubアカウントは不要です。まずお手本を見て、PCなら内蔵カメラで「ひとりで練習」を試せます。
公開直後や更新直後は、Actionsの「Publish Pumpkin Toss」が完了するまでページに反映されません。

公開と共同編集の手順は [CONTRIBUTING.md](CONTRIBUTING.md) にまとめています。
GitHub Pages用の自動公開を用意しています。`main` を更新すると、テストを通過したアプリを公開します。
カメラ映像は各端末で処理し、GitHubへ映像を送ることはありません。

## 自分のPCで起動

1. このフォルダーの `start.cmd` をダブルクリックします。
2. ブラウザーで `http://localhost:4173/` を開きます。PCのEdge / Chromeで試してください。
3. まず「お手本を見る」か「マウスで試す」。手で遊ぶときは「カメラで2人プレイ」を押して、カメラ使用を許可します。
4. 終了時は「カメラを停止」。サーバーも終了する場合は起動用ウィンドウで `Ctrl+C` を押します。

すでにサーバーが起動中なら、ページを開くだけで使えます。更新が反映されていないときは再読み込みしてください。
再読み込みすると、作った顔は消えます。`index.html` の直接起動には対応していません。
起動スクリプトは既存のNode.jsを探します。別のPCにはNode.jsと `public/vendor` フォルダーも必要です。npmパッケージのインストールは不要です。

## 体験の流れ

- **お手本を見る：** イラストの2人が、つかむ → 投げる → かぶる、を自動で実演します。実際の検出映像ではありません。
- **マウスで試す：** 左のカボチャをドラッグし、右の相手に向けて素早く動かしながら離します。「もう一度投げる」で繰り返せます。
- **カメラで2人プレイ：** 画面の左が投げる人、右がかぶる人。2人の顔が左右の枠に映るとカボチャが出ます。手をカボチャに重ねてにぎる（親指と人差し指でつまんでも可）→ 相手の方向へ振りながら手を開く、で投げます。
- **かぶる：** 相手の頭に着地し、顔の位置・大きさ・向きに追従します。顔が見えなくなるとカボチャを隠します。画面内の「もう一度」に手を約1.2秒重ねるか、ボタンを押すと次の投球です。
- **ひとりで練習：** 自分は左に映ります。右のイラストの相手に、本物の手の動きで投げられます。相手には「練習用」と表示します。
- **かぼちゃを作る：** まる・たて長・よこ長を選び、マウスで表面をなぞるか、カメラに映る指先をつまんで動かして削ります。「顔を消す」で白紙から作れます。「できた！」で、自分の顔を彫ったカボチャを投げる体験へ戻れます。

2人モードでは、顔が1人だけのときにその人へ投げることはありません。手を見失った場合も勝手に投げません。
役割は画面内の左右で決めます。人物の同一性は識別しないので、2人は立ち位置を交換せずに遊んでください。
顔2人、手2本までを検出します。投げる人の手が見やすいようにし、受ける人は手を下げると試しやすくなります。
カメラは鏡表示が初期設定です。画面に重なる仮想カボチャを操作するため、実物の道具を持つ必要はありません。

## 会場で使う場合

「会場のイメージ」に配置図があります。
PCを大きなモニターやプロジェクターにつなぎ、画面を複製して「全画面」にします。
カメラをスクリーンの近くに置き、2人の顔と手が同時に映る位置に立ちます。まずPC画面と内蔵カメラで距離を試してください。

スタッフ用の「設定」から、左右の役割入れ替え、鏡表示、前面・背面カメラ、効果音、ボタンによる投球補助を使えます。
前面・背面の指定は希望値です。ブラウザーが別のカメラを選ぶこともあります。USBカメラを機種名で選ぶ機能は未実装です。

## 実装範囲と確認状況（2026-10-01）

- カメラ映像の上に立体のカボチャを重ねる、固定カメラ用のAR表現です。
- 正面に彫った模様は、立体表面の穴として残ります。自由な3D造形や、厚みのある断面のモデリングには未対応です。
- 手の奥行きによる隠れ方、床・机の認識、カメラを持って歩く空間AR（SLAM）は未対応です。
- マウスの投球・着用・彫刻と、お手本表示をブラウザーで確認しています。
- 自動テストでは、単独の顔を相手にしない役割判定、手の継続追跡、逆方向・遅すぎる投球の抑制、途中で手が外れたときの待機解除、着地位置、顔の姿勢変換などを確認しています。
- **実際のカメラでの手・顔の認識精度、2人での遊びやすさ、プロジェクターでの見え方は未確認です。** この版を使って現場で調整してください。
- スマホ向けの表示は用意していますが、iPhone / Androidの実機カメラでは未確認です。スマホではGitHub PagesのHTTPSの共有URLから開いてください。ローカル起動の `localhost` は起動したPC専用です。

検出モデルの起動確認は `http://localhost:4173/diagnostics.html`。カメラを使わず白紙画像を処理します。
テストは `node --test tests/*.test.mjs` で実行します。
以前の編集中心の画面は `http://localhost:4173/workshop.html` に残しています。新しい体験画面とは模様を共有しません。

## 映像と依存データ

カメラ映像はこのPC内で処理します。音声の取得・録画・映像送信は実装していません。
通常の起動にはネット接続は不要です。検出用ライブラリ・モデルとThree.jsは `public/vendor` に保存済みです。
大きなモデル類はGitの対象外なので、フォルダーを移す場合は `public/vendor` もコピーしてください。
データが欠けている場合だけ `node scripts/download-assets.mjs` で再準備します。出典・ライセンスは `THIRD_PARTY.md` に記載しています。
