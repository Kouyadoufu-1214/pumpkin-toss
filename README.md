# Pumpkin Toss — スクリーンで遊ぶ文化祭プロトタイプ

2026年10月25日の文化祭に向けた、PC・会場スクリーン用の試作です。
大きなスクリーンにカメラ映像を映し、片方の人が手に乗せて投げたカボチャを、もう片方の人が画面の中でかぶります。
最初は何も彫られていないかぼちゃを作り、完成したら投げる画面へ進みます。投げ終わったら、作品を展示するか選べます。保存した制作途中の作品がある場合は、その続きから始まります。

## 自分のPCで起動

`public/index.html` のダブルクリックでは起動できません。ブラウザーの制限でアプリを読み込めないため、上の共有URLを開くか、次の手順で起動してください。

1. このフォルダーの `start.cmd` をダブルクリックします。
2. ブラウザーで `http://localhost:4173/` を開きます。PCのEdge / Chromeで試してください。
3. かぼちゃを彫り、「完成！ かぼちゃを投げる」で次の画面へ進みます。手で投げるときは「手で投げる・2人プレイ」を押して、カメラ使用を許可します。
4. 終了時は「カメラを停止」。サーバーも終了する場合は起動用ウィンドウで `Ctrl+C` を押します。

すでにサーバーが起動中なら、ページを開くだけで使えます。更新が反映されていないときは再読み込みしてください。
制作途中はこのブラウザーに自動保存され、再読み込みしても続きから作れます。「作品ファイルを保存」でも残せます。`index.html` の直接起動には対応していません。
起動スクリプトは既存のNode.jsを探します。別のPCにはNode.jsと `public/vendor` フォルダーも必要です。npmパッケージのインストールは不要です。

## 体験の流れ

- **かぼちゃを作る：** 最初の画面でマウスをドラッグして彫ります。カメラ使用中は、親指と人差し指をつまんで描けます。描いている間は細い下書きが見え、離したときに手ぶれを整えて削ります。「完成！ かぼちゃを投げる」で投げる画面へ進みます。
- **映像＋マウスで投げる：** カメラ映像をリアルタイム表示しながら、左のカボチャをドラッグして相手へ離します。顔を検出すると頭に追従します。検出できないときも、画面の顔をクリックしてかぶせる位置を指定できます。「顔への自動追従に戻す」で手動指定を解除します。カメラを使わず遊ぶ場合は「カメラなしで試す」を選びます。
- **手で投げる・2人プレイ：** 画面の左が投げる人、右がかぶる人。左半分で指を少し丸めると、手にかぼちゃが現れます。完全なグーにする必要はなく、投げる人の顔が未認識でも持てます。持った後は中間の手の形でも保持し、相手の方向へ手を振りながら指を開き切ると投げます。途中まで開いただけでは離れません。最初からパーを映すだけでは持たず、手を止めて開くだけでも投げません。画面の丸印で認識状態を確認できます。左右を入れ替えた場合は右半分で手を軽く握ります。
- **かぶる・展示する：** 相手の頭に着地し、顔の位置・大きさ・向きに追従します。顔が見えなくなるとカボチャを隠します。着地後に「このかぼちゃを展示する？」と表示され、展示室へ進む・もう一度投げる・彫り直す、を選べます。
- **頭全体への自動フィット：** 顔の輪郭36点から幅・高さ・傾きを測り、耳の左右と髪のある頭頂部を含めた頭の範囲を推定します。かぼちゃの中心を頭頂部側へ寄せ、丸い外周で頭を覆うよう調整します。近づく・離れる動きにも追従します。「設定 → 髪・耳まで覆うサイズ」で80〜160%に微調整でき、100%に戻せます。髪の毛を一本ずつ検出する方式ではないため、大きな髪型や帽子はサイズを上げて調整してください。
- **ひとりで練習：** 自分は左に映ります。右のイラストの相手に、本物の手の動きで投げられます。相手には「練習用」と表示します。
- **お手本を見る：** 投げる画面から、イラストの2人による、軽く握って持つ → 開いて投げる → かぶる、の自動実演を見られます。実際の検出映像ではありません。

### 自由に顔を描く

- **囲んで抜く：** 目や大きな口の輪郭を一筆で描き、描き始めの丸に戻ってから離すと、中を切り抜きます。少しの隙間はつなぎます。輪郭が大きく開いている場合は切り抜かず、描き直しの案内を出します。
- **線で削る：** 細い笑い口や模様を描き、離すと線のまま削ります。太さも選べます。
- **手ぶれ補正：** 軽め・標準・強めの3段階。用意された目・口の形に置き換えるのではなく、自分で描いた線をなめらかにします。
- **ひとつ戻す：** 一筆分の切り抜きを戻します。手を見失った場合、表面から外れた場合、ページを切り替えた場合は、途中の下書きを取り消します。

まる・たて長・よこ長でかぼちゃ本体の形を選べます。細かい模様はマウスで描けます。手で描くときは、最初は大きな目や口から試してください。

2人モードでは、顔が1人だけのときにその人へ投げることはありません。手を見失った場合も勝手に投げません。
役割は画面内の左右で決めます。人物の同一性は識別しないので、2人は立ち位置を交換せずに遊んでください。
顔2人、手4本までを検出します。投げる人の手が見やすいようにし、受ける人は手を下げると試しやすくなります。

顔の検出・存在・追跡の信頼度しきい値は0.3です。顔の短い検出抜けは手操作・マウス操作ともに最後の実測から1.4秒、持っている手の検出抜けは1.5秒まで補います。手が少し見切れても、かぼちゃを画面内に残して待ち、近くへ戻った同じ手で続けられます。指が見切れて開いたように見えるだけでは手を離しません。長い見切れの間の移動を投球の勢いには使わず、手を見失ったこと自体でも投げません。通常は相手方向への動きと、指が開き切ったパーを合わせて確認し、初期設定では2回以上・40ms以上の観測で投げます。その間の短い検出抜けにも対応します。すでに相手へ動き始めている手が大きく速く振られ、指が開き切った状態を確認できた場合は、その観測ですぐ投げます。傾いた手には3D手指座標も使います。

持つ操作は指を少し丸めた時点で認め、離す操作は指の伸び方も確認します。認識モデルが「パー」と返しても、指がまだ曲がっている間は保持します。持つ・離すの間にある手の形は、持っている状態を変えません。以前の「手が映れば自動で持ち、パーのまま振る」操作は、軽く握ってから開く操作に変更しました。

手の結果は顔の処理終了を待たず反映します。手操作中の顔認識は自動・軽量で240ms、高画質で160ms間隔です。かぼちゃの表示には最大90ms・160pxまでの位置予測と初期値65msの柔らかな追従を使います。補正による追加の遅れは90pxまでに抑え、投球の判定には実際に検出した座標だけを使います。模擬映像と自動テストは確認済みですが、会場の距離・照明・実際のカメラでの認識精度は本番前に試してください。
カメラは鏡表示が初期設定です。画面に重なる仮想カボチャを操作するため、実物の道具を持つ必要はありません。

### 開発者モード・会場での調整

**F2** または **設定 → 開発者モード** で表示します。全画面中も利用でき、入力欄を操作中のF2は無視します。通常は非表示です。

- 手のボーンは補正前の検出座標。操作中の手は橙、ほかの手は水色です。かぼちゃだけが遅れるのか、手そのものの認識が抜けているかを見分けられます。
- 「画面のFPS」と「手の検出/秒」は別々に表示します。手・顔の処理時間、手の遅れ、モデルが認識したグーパー、実際の指の開き具合、速度・距離、パーの確認、動作履歴、直近の失敗理由も確認できます。「軽く握る → 相手へ振る → しっかり開く → 投球」の段階と、まだ指を開いている途中かを表示します。値は端末内だけで扱います。
- 最低速度は160px/s、最低距離32px、パーの確認時間40ms、パーの信頼度70%が初期値です。その場で調整でき、端末内に保存されます。「標準に戻す」で初期値に戻せます。速度・距離は画面上の1280×720座標です。方向や観測時間の条件もあるため、速度・距離だけで投球が決まるわけではありません。
- 「表示のふわり補正」を増やすと見た目がなめらかになります。0msで補正を切れます。ボーンと投球の座標は変わりません。
- 描画品質「自動」は軽量から始め、描画に余裕が続く場合だけ高画質にします。重くなれば軽量へ戻ります。「軽量」「高画質」で固定もできます。軽量時の3D描画は832×468（従来より描画ピクセル数57.75%減）ですが、操作座標は変わりません。
- 認識へ渡す画像の長辺は自動・軽量768px、高画質960px。自動で描画が高画質になっても認識画像は大きくしません。展示の確認画面では不要な手認識を休止し、開発者モードを開くと再開します。

画面FPSが高いまま手の検出/秒が低ければ認識側の待ち時間、ボーンが消える場合は検出抜け、画面FPS自体が低ければ描画を含む全体の負荷を調べます。開発者パネルの文字更新は最大5回/秒、閉じている間は文字・ボーンを更新しません。

## 会場で使う場合

「会場のイメージ」に配置図があります。
PCを大きなモニターやプロジェクターにつなぎ、画面を複製して「全画面」にします。
カメラをスクリーンの近くに置き、2人の顔と手が同時に映る位置に立ちます。まずPC画面と内蔵カメラで距離を試してください。

スタッフ用の「設定」から、左右の役割入れ替え、鏡表示、前面・背面カメラ、効果音、ボタンによる投球補助を使えます。
カメラ許可後は「使うカメラ」から接続機器を選び、「このカメラで再開」を押せます。Switch 2 カメラも、OS・ブラウザーがカメラとして認識した場合はここから選べます。前面・背面の指定は「自動で選ぶ」ときの希望値です。

## かぼちゃの3D素材（2026-10-16）

Higgsfieldの3D Jutsuで本体・木質のヘタ・葉を制作し、約1.5MBのGLBとしてアプリに組み込みました。皮の色むら・細かな凹凸・つやの違いを512pxのテクスチャに保存しています。素材はアプリと一緒に配信するため、遊ぶ人のHiggsfieldへのログインや生成処理は不要です。

描いた目や口には厚みのある切り口が付きます。内側からの暖かな光、ゆるやかな光の揺れ、横から見た果肉の厚みを表現しています。裏側は閉じたままです。読み込み中・失敗時は内蔵の形状で遊べます。

制作元は[Higgsfieldのプロジェクト](https://higgsfield.ai/3d-jutsu/dbfbe1f5-d3c0-4655-bbad-2056a80c442a)（所有者のログインが必要な場合があります）。再制作用のコードは `scripts/higgsfield-pumpkin.py`。通常の制作・投球では映像や模様を送信しません。展示するときだけ、彫った模様・本体の形・作品名・ニックネームを共通展示室へ送ります。

## 実装範囲と確認状況（2026-10-24）

- カメラ映像の上に立体のカボチャを重ねる、固定カメラ用のAR表現です。
- 正面に彫った模様は、立体表面の穴として残り、切り口の厚みも表示します。自由な3D造形や、裏面の彫刻には未対応です。
- 手の奥行きによる隠れ方、床・机の認識、カメラを持って歩く空間AR（SLAM）は未対応です。
- マウスの投球・着用・彫刻と、お手本表示をブラウザーで確認しています。
- 自由描画の補正、輪郭の切り抜き、線の彫刻、一筆単位の取り消しを追加しました。自動テストで手ぶれ低減・サンプル間隔による差・未閉鎖の輪郭・追跡中断を検証しています。新しい補正を使う実際の手の描き心地は、カメラで試して調整してください。
- 自動テストでは、単独の顔を相手にしない役割判定、手の継続追跡、逆方向・遅すぎる投球の抑制、途中で手が外れたときの待機解除、着地位置、顔の姿勢変換などを確認しています。
- MediaPipe Gesture Recognizer と手指の座標を使い、軽く丸めた手で持ち、開き切った手で投げます。強いグーの認識は不要ですが、パーの分類だけでは離さず、指の伸び方も確かめます。低い検出頻度や手を開く判定の遅れに対応し、手・顔の検出に失敗しても映像を残してマウス操作を続けられます。カメラの切替・故障・キャンセル時の状態遷移は自動テスト、モデルの実行と動くテスト映像を使ったマウス投球はブラウザーで確認しています。
- 顔へのフィットは、実3Dモデルを使った投影寸法の自動テストと、既知サイズの検証用映像で遠近・傾きへの追従を確認しています。描画頻度が変わっても追従の遅れが変わらないよう平滑化しています。
- **実際のカメラでの手・顔の認識精度、2人での遊びやすさ、プロジェクターでの見え方は未確認です。** この版を使って現場で調整してください。
- PCと会場のスクリーンでの利用を対象にしています。共有URLはPCのブラウザーで開いてください。ローカル起動の `localhost` は起動したPC専用です。

検出モデルの起動確認は `http://localhost:4173/diagnostics.html`。カメラを使わず白紙画像を処理します。
テストは `node --test tests/*.test.mjs` で実行します。
以前の編集中心の画面は `http://localhost:4173/workshop.html` に残しています。新しい体験画面とは模様を共有しません。

## 映像と依存データ

## 彫刻と共通展示室

- 「少しずつ削る」で皮をなぞり、指をはなして同じ場所を重ねて削ると穴が開きます。
- 「囲んで抜く」は大きな目や口、「線で削る」は細い模様、「埋め直す」は修正に使えます。
- 「戻す」「やり直す」は一筆単位です。途中の作品は端末に自動保存します。
- 投げ終わった後の「展示室へ進む」で展示室が開きます。作品名とニックネームを付け、公開の確認にチェックして展示します。
- 作品が細かくリンクに収まらないときは作品ファイルを保存し、展示室で読み込みます。
- 展示にはデータ量の上限があります。上限を超えた細かな作品も端末・作品ファイルには保存できます。展示する場合は模様を少し減らしてください。
- 共通展示室: https://pumpkin-lantern-gallery.higgsfield.app/
- 「スクリーン展示」は作品を10秒ごとに切り替えます。停止・前後移動・全画面に対応します。
- 「自分の作品」から取り下げと再展示ができます。展示したブラウザーのCookieを消すと所有確認ができなくなるため、同じブラウザーを使ってください。
- 展示作品は公開です。本名ではなくニックネームを使用してください。カメラ映像は送信しません。
- 制作画面はGitHub Pages、展示の保存先はHiggsfieldのD1です。ローカル保存だけで他端末へ共有しているわけではありません。
- 入口の映像は既存のHiggsfield製3Dモデルから描画しています。有料の動画生成は使っていません。
